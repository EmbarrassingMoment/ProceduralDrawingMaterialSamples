# Material Catalog

Every material and material function in this project. Generated by `python Tools/ListMaterials.py`; do not edit by hand.

- Materials: 177 (Surface 122 / UI 11 / Post Process 44)
- Material Functions: 91
- Material Instances: 85

How to read the tables:

- **Domain** tells you where a material goes. Apply **Surface** to a mesh such as a Plane, set **UI** as the brush of a UMG Image, and add **Post Process** to the Materials array of a Post Process Volume.
- **Showcase** names the `Content/Levels/Showcase_<name>` level that displays the material.
- **Instances** is the number of Material Instances made from the material.
